# Web Slotera

Aplicación inicial React, Vite y TypeScript. Aún no implementa rutas, permisos ni comunicación con la API. Requiere Node 24 y pnpm 10.33.0.

Desde esta carpeta ejecutar `pnpm install --frozen-lockfile` y `pnpm dev`. `pnpm lint` verifica el código y `pnpm build` ejecuta TypeScript y genera la compilación. La interfaz generada es provisional.
