# Aprendizaje Java y Spring

| Concepto | Aplicación / ejercicio |
|---|---|
| POO, encapsulamiento | Booking con transición controlada |
| Interfaces, polimorfismo | Puertos y estrategias de precio/confirmación |
| Records, enums | DTOs, estados y roles |
| Collections, Streams, Generics, Optional | Filtrar y transformar intervalos y resultados |
| Excepciones | Errores de dominio y ProblemDetail |
| BigDecimal | Cálculo y redondeo de tarifa |
| Java Time | Instant, ZoneId, LocalTime, intersecciones |
| Concurrencia | Reproducir carrera y corregirla con DB |
| CompletableFuture | Explorar ejecución asíncrona fuera de transacción |
| Anotaciones, DI | Beans, configuración, servicios |
| JDBC, JPA | SQL real, relaciones, consultas y transacciones |
| Maven, JUnit | Build reproducible y pruebas |

Patrones: Strategy (políticas), State (ciclo), Repository (persistencia), Adapter (correo/S3), Observer (eventos), Factory Method (creación), Specification (filtros), DI, Transactional Outbox/registro de eventos (fiabilidad). Usarlos solo cuando resuelvan un problema.
