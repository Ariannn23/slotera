## Dashboard
Reservas hoy, pendientes, tasa ocupación (tiempo ocupado por reservas / tiempo reservable, definición exacta pendiente), importe de reservas completadas, cancelaciones, gráfica por día. No presentar importes como dinero cobrado. Calendario diario/semanal/mensual con filtros.

Portal público: catálogo → disponibilidad → datos → revisión/confirmación → gestión segura. Mostrar error de conflicto con opción de recargar horarios. Prioridad funcional sobre animaciones.
